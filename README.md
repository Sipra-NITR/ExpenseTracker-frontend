# Expense Tracker Frontend

This repository contains the frontend of the Expense Tracker application built using React and Vite.

## Features

- Secure Login & Registration
- JWT Authentication
- Dashboard
- Expense Management
- Expense Category Pie Chart
- Monthly Expense Bar Chart
- PDF Export
- Responsive UI

## Tech Stack

- React
- Vite
- Tailwind CSS
- Axios
- React Router DOM
- Recharts
- jsPDF

## Run Locally

```bash
git clone <frontend-repository-url>

cd expense-tracker-frontend

npm install

npm run dev
```

Backend should be running on

```
http://localhost:8080
```
